# Audio Salvage UK - New Project Setup Guide

## 1. Create External Supabase Project

1. Go to [supabase.com](https://supabase.com) and create a new project
2. Run `database-export.sql` in the **SQL Editor** to create all tables, functions, triggers, RLS policies, and storage buckets

## 2. Create New Lovable Project

1. Create a new project in Lovable
2. Connect your external Supabase project via **Settings → Connectors → Supabase**
3. Import this codebase (via GitHub or copy files)

## 3. Required Secrets (Supabase Edge Functions)

Set these in your Supabase project's **Edge Function Secrets**:

| Secret | Purpose |
|--------|---------|
| `RESEND_API_KEY` | Email sending via Resend (signup verification, password reset) |
| `FCM_SERVER_KEY` | Firebase Cloud Messaging for push notifications |

> `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are auto-provided to edge functions.

## 4. Edge Functions

Deploy these 3 edge functions to your Supabase project:

| Function | JWT Verify | Purpose |
|----------|-----------|---------|
| `send-auth-email` | `false` | Custom branded auth emails via Resend |
| `send-push-notification` | `false` | FCM push notifications for status changes |
| `driver-setup` | `false` | Driver account provisioning from invite tokens |

### Auth Email Hook

In Supabase Dashboard → **Authentication → Email Templates → Email Hook**:
- Set the hook URL to your `send-auth-email` edge function URL

## 5. Supabase Auth Configuration

- **Email Confirmations**: Currently disabled (users sign in immediately after registration)
- **Site URL**: Set to your app's published URL
- **Redirect URLs**: Add your app URL + `/reset-password`

## 6. Resend Configuration

- Domain: `notification.audiosalvageuk.co.uk`
- From: `Audio Salvage UK <noreply@notification.audiosalvageuk.co.uk>`

## 7. Admin User Setup

After running the SQL, manually create an admin user:

1. Sign up a user normally through the app
2. In Supabase SQL Editor, run:
   ```sql
   UPDATE public.profiles SET role = 'admin' WHERE email = 'your-admin@email.com';
   ```

## 8. Files to Keep

All source code in `src/` works as-is with an external Supabase connection. The key integration files:

- `src/integrations/supabase/client.ts` - Auto-generated by Lovable when you connect Supabase
- `src/integrations/supabase/types.ts` - Auto-generated from your schema
- `supabase/functions/*` - Deploy to your Supabase project

## 9. Capacitor (Native App)

For iOS/Android builds:
- `capacitor.config.ts` - Update `server.url` to your new Lovable project URL
- Run `npx cap sync` after updating
